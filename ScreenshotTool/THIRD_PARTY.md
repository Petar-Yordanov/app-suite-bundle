# Dependencies

- Qt 6: Core, Gui, Widgets, Qml, Quick, Quick Controls, Network, Concurrent and Linux DBus; consult the Qt distribution's LGPL/GPL/commercial notices and source availability requirements.
- Linux: Xlib, XRandR and XFixes (system libraries); xdg-desktop-portal (system service).
- Windows and macOS: operating system SDK frameworks and runtime libraries.
- Optional benchmark script: psutil (not included in the application or installers).

Qt is dynamically linked in deployed installers. Redistribution must comply with the applicable Qt and system component licenses.
