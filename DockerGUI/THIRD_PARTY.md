# Dependencies

* Qt 6 (LGPLv3/GPL/commercial licensing as applicable), dynamically linked.
* Docker CLI, Docker Engine, and Docker Compose plugin are external user-installed
  software. They are not redistributed by the frontend or its installers.
* Xmake, compiler, packaging tools are build-time dependencies.

The generated installer bundles the necessary Qt runtime libraries and QML
modules. Review the applicable Qt license obligations if redistributing.
